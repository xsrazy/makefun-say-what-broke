One line of error copy that tells the brutal truth about what broke and lands a laugh, entered in make.fun's "Say What Actually Broke" bounty.

## Run it

```sh
python3 main.py
```

The program writes exactly one line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline.
